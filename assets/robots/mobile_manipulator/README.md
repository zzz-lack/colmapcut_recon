# 移动机械臂资产 / Mobile Manipulator Asset

## 中文

`urdf/combined_source.urdf` 是原始展开 URDF 的只读副本，`urdf/combined_mobile.urdf` 是面向 Isaac Sim 的修复候选。Lite6 的 visual/collision mesh 直接保存在 `urdf/uie_description/`；TerraSentia 底盘和传感器 mesh 来自 `urdf/terrasentia_gazebo/` Git 子模块。克隆仓库后运行 `git submodule update --init --recursive` 获取完整 mesh 依赖。

导入器会合并 fixed joints，因此运行时通过 schema/名称查找 articulation root 和末端相机，而不依赖导入器生成的嵌套 prim 路径。机器人与仿真资产路径在 `configs/simulation/tomato_orbit.toml` 修改；Isaac Sim/OpenUSD 等外部依赖见 `docs/EXTERNAL_DEPENDENCIES.md`。

## English

- `urdf/combined_source.urdf` is an untouched copy of the supplied expanded URDF.
- `urdf/combined_mobile.urdf` is the Isaac Sim mobile-base repair candidate.
- `urdf/uie_description/` and `urdf/terrasentia_gazebo/` preserve all relative mesh paths.
- Run `git submodule update --init --recursive` after cloning to fetch the
  TerraSentia chassis and sensor mesh dependencies.
- `usd/combined_mobile_merged/combined_mobile_merged.usd` is generated by
  `scripts/isaac/02_import_robot_usd.py`; do not hand-edit its generated
  configuration layers.

The repair candidate keeps the original kinematic dimensions except where the four
locked suspension joints are converted to fixed joints. Their non-zero locked angles
are baked into the fixed transforms, so the wheel poses stay unchanged.

The importer merges fixed joints to reduce the PhysX body count. Runtime scripts
therefore resolve the articulation root and end-effector camera frame by schema/name
instead of assuming importer-generated nested prim paths.
